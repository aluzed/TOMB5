Ce qui est franchi

RE928 s'arrêtait avant le store BIU_CONFIG. Ici le registre est modélisé selon la source épinglée (valeur stockée, atteinte des écritures RAM uniquement en configuration cache normal) et l'exécution réelle continue : flushCache avec fenêtre cache isolé puis cache normal, initialisation des registres CP0, copie de données, effacement BSS, pile, registre de taille RAM, traces POST/EXP2.

Exécutions fresh et restored reproduites, toutes deux à la même frontière. 256 stores RAM abandonnés en fenêtre isolée. Oracle BIU compilé concordant. Contrôle négatif « cache isolé dès le départ » : échec réel de préfixe conservé. La frontière atteinte est insensible au choix de modélisation de l'isolation.
